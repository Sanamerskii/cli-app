# Граф зависимостей Maven

Консольная программа на Java строит граф зависимостей Maven-пакета рекурсивным обходом в глубину.
Нужен JDK с командами `java` и `javac`.

CSV содержит по одной паре `ключ,значение` на строке, без заголовка и запятых в значениях:

```csv
package,org.example:demo
repository,https://repo.maven.apache.org/maven2
testMode,false
version,1.0
output,graph.svg
ascii,false
filter,
```

`package` — Maven-координаты groupId:artifactId; в тестовом режиме — имя из заглавных латинских букв.
`repository` — URL Maven-репозитория или путь к файлу тестового репозитория.
`testMode` включает тестовый режим, `version` задаёт версию, `output` — имя SVG-файла,
`ascii` включает вывод дерева, `filter` задаёт исключаемую подстроку. Логические значения: `true` и `false`.

Запуск и сборка: `./run.sh путь/к/config.csv`. Проверка: `./run.sh --test`.

Зависимости выводятся в формате `groupId:artifactId:version`. Программа учитывает свойства,
родительские POM, управление версиями зависимостей и импорт BOM. Если версия не определена,
программа сообщает об ошибке.

В тестовом режиме файл репозитория содержит строки `A,B` для ребра от A к B и `A` для отдельного
пакета. Имена состоят из заглавных латинских букв. Циклы обрабатываются без повторного обхода.

На этапе 4 программа выводит порядок, в котором каждая зависимость предшествует зависящему от неё
пакету. При цикле такой порядок невозможен, поэтому выводится ошибка.
Для `junit:junit:4.13.2` порядок программы: `hamcrest-core:1.3`, `hamcrest-library:1.3`,
`junit:4.13.2`. Apache Maven (`mvn -f junit-4.13.2.pom dependency:tree`) показывает те же
зависимости и отмечает повторный `hamcrest-core` и область `test` для `hamcrest-library`.
Maven выводит дерево, а не гарантированный порядок загрузки: на него влияют кэш и параллельные загрузки.
