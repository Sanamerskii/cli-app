# Визуализатор зависимостей Maven

Консольное приложение на Java строит граф зависимостей Maven-пакета, выводит его описание в формате DOT и сохраняет изображение в SVG. Данные о зависимостях читаются из POM-файлов репозитория без использования Maven или библиотек для получения зависимостей.

## Требования

- JDK 16 или новее: команды `java` и `javac` должны быть доступны в `PATH`.
- Graphviz: команда `dot` должна быть доступна в `PATH`.
- Для работы с удалённым репозиторием требуется подключение к сети.

## Запуск

Создайте файл `config.csv` в корне проекта:

```csv
package,junit:junit
repository,https://repo.maven.apache.org/maven2
testMode,false
version,4.13.2
output,graph.svg
ascii,true
filter,
```

Из корня проекта выполните:

```sh
./run.sh config.csv
```

Скрипт компилирует исходный код в `build/` и запускает программу. Описание графа в формате DOT выводится в консоль; изображение сохраняется в `graph.svg`. Если `ascii` равно `true`, после DOT выводится дерево зависимостей. При обнаружении цикла в дереве повторная ссылка помечается `(cycle)`.

Пути в настройках разрешаются относительно корня проекта, поскольку скрипт перед запуском переходит в эту папку.

## Настройки

Файл содержит ровно семь строк `ключ,значение`, без заголовка. Порядок строк произвольный; каждый ключ указывается один раз. Запятые внутри значений и пустые строки не поддерживаются.

| Ключ | Значение |
| --- | --- |
| `package` | Координаты `groupId:artifactId`; в тестовом режиме — имя из заглавных латинских букв. |
| `repository` | URL Maven-репозитория по HTTP или HTTPS либо путь к файлу тестового графа. |
| `testMode` | `true` для тестового графа, `false` для Maven-репозитория. |
| `version` | Версия анализируемого пакета; обязательна и в тестовом режиме. |
| `output` | Путь к изображению с расширением `.svg`. |
| `ascii` | `true` включает вывод дерева, `false` отключает. |
| `filter` | Подстрока для исключения зависимостей по имени; пустое значение отключает фильтр. |

При неверных параметрах, недоступном POM или ошибке Graphviz программа выводит сообщение об ошибке и завершает работу с ненулевым кодом.

## Тестовый граф

Создайте, например, `repository.csv`:

```text
A,B
A,C
B,C
C,A
```

Строка `A,B` означает зависимость A от B. Строка `A` задаёт пакет без перечисления зависимостей. Имена состоят только из заглавных латинских букв; пробелы в строках графа не допускаются. Циклы учитываются при построении графа и не вызывают бесконечный обход.

Для этого файла используйте конфигурацию:

```csv
package,A
repository,repository.csv
testMode,true
version,1
output,test-graph.svg
ascii,true
filter,
```

## Проверка

```sh
./run.sh --test
```

Команда проверяет настройки, обработку родительских POM и импортируемого BOM, а также обход тестового графа с циклом и фильтрацией.

## Особенности обработки Maven

Программа читает зависимости из POM, учитывает свойства, родительские POM, `dependencyManagement` и импорт BOM. Это не полная реализация Maven: в частности, не воспроизводятся все правила профилей, областей зависимостей, исключений и разрешения конфликтов версий. Поэтому для некоторых пакетов результат может отличаться от `mvn dependency:tree` или программа может сообщить об ошибке разрешения версии.

Для проверки можно попробовать пакеты `junit:junit` версии `4.13.2`, `org.hamcrest:hamcrest-core` версии `1.3` и `org.hamcrest:hamcrest-library` версии `1.3`.

## Этапы работы

Ветки `stage1`–`stage5` содержат последовательные этапы: конфигурацию, получение прямых зависимостей, построение графа, порядок загрузки и визуализацию. В `main` находится итоговая версия. На этапе 4 порядок загрузки выводится в ветке `stage4`; при цикле строгий порядок невозможен.
